# ThinkBefore — AI Decision Checker

> Think before you act.

ThinkBefore is an AI-powered decision-support web application designed to help users pause before making a decision, identify possible risks, verify important details, and consider safer alternatives.

## 🚀 Features

- 🔐 User Registration & Login
- 🤖 AI Decision Analysis
- ⚠️ Risk Level Detection
- 🔎 Possible Concerns
- ✅ Things to Verify
- 🛡️ Safer Alternatives
- 📜 Decision History
- 🔍 Search Saved Decisions
- 👤 User Profile
- 🗄️ MySQL Database
- 🎨 Responsive Purple UI

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- Flask
- REST API

### Database
- MySQL

### AI
- AI-based decision analysis
